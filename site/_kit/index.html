Every phone screen and every scene the site uses. This page is not deployed.

Placing things on a page

Include assets/site.css, assets/kit.css, then assets/kit.js and assets/kit-more.js, both with defer. Everything with the classes below is set up on load.

<!-- A scene: computer and phone side by side (stacked when narrow), with controls. -->
<div class="pk-scene" data-scene="question">
  <noscript><img class="pk-still-img" src="/assets/frames/question.webp" width="1100" height="660" alt="..."></noscript>
</div>

<!-- Options on a scene -->
data-layout="phone"   the phone only        data-layout="stack"   phone under computer at any width
data-step="3"         held still at step 3 (zero-based), no autoplay

<!-- A single phone screen, no motion of its own besides spinners. Width: --pk-w (default 300px). -->
<div class="pk-phone" data-screen="sessions" style="--pk-w:280px"></div>

URL, for screenshots:   ?scene=question&step=2   holds that scene at that step
                        ?still                    holds every scene at its poster step, spinners stopped
                        ?theme=light|dark         forces the page theme

The scene fills its container's width; the page decides the width. Scenes play only while at least a third is on screen, pause when the tab is hidden, and with reduced motion they do not play at all: Previous and Next walk the steps.

Part two: kit-more.js

Screens take their params from a view or a scene step; with none they show the state listed first.

changes     session + Changes sheet      { sheet: 0 (closed), file: 2 (theme.ts's diff) }
details     session + Session details    { sheet: 0, top: 1 (feed lands on the since rule), scroll (0..314), muted }
terminal    the Terminal tab (fit)       { feed: 1 + s: session params (the Feed tab), lines, z: 13 (text size), go (tab just switched) }
settings    Settings                     { scroll (0..358), rel: '0.27.0' (a release is out) }
failure     Can't reach workstation      { busy: 'Restarting portholed over SSH…' }
failsafe    SSH shell, from Settings     { down: 1 (from the failure card), lines }
shade       notification shade           { n: [{ k, t, x, w (working seconds), r (Reply), ri (reply text) }] }
ainst       Android's installer (overlay){ upd: 1 (Porthole's own update) }

Views: changes-diff, details-switches, session-since, settings-update, settings-away,
       banner-update, banner-build, install (sessions + banner, installer over it)
Scenes: changes (4 steps, poster 1, phone only), terminal (5, poster 2), builds (5, poster 1),
        notify (4, poster 1), since (5, poster 1, phone only), failsafe (4, poster 1),
        update (3, poster 0, phone only)
