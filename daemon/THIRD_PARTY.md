# Third-party software in portholed

`portholed` is compiled from the Go modules below, as pinned in `go.mod` and `go.sum`,
together with the Go standard library. Their licences require the notices in this file
to accompany any distribution of the binaries.

| Module | Version | Licence |
|---|---|---|
| [github.com/coder/websocket](https://github.com/coder/websocket) | v1.8.15 | ISC |
| [github.com/creack/pty](https://github.com/creack/pty) | v1.1.24 | MIT |
| [github.com/fsnotify/fsnotify](https://github.com/fsnotify/fsnotify) | v1.10.1 | BSD-3-Clause |
| [github.com/skip2/go-qrcode](https://github.com/skip2/go-qrcode) | v0.0.0-20200617195104-da1b6568686e | MIT |
| [golang.org/x/sys](https://pkg.go.dev/golang.org/x/sys) | v0.13.0 | BSD-3-Clause |
| [Go standard library](https://go.dev) (includes its vendored golang.org/x/crypto, x/net and x/text) | toolchain | BSD-3-Clause |
